# Shapes Design · 基于坐标的形状设计

> 课程作业：以点为基础组建不同形状（点、圆、三角形），含合法性检查与进阶扩展（特殊三角形、椭圆、多边形），并附交互式可视化界面。

## 功能特性

- **Point**：平面点，含两点距离计算
- **Circle**：圆心（Point）+ 半径，判断任意点在**圆内 / 圆上 / 圆外**
- **Triangle**：三个 Point 成员 + **合法性检查**（三点共线、两边之和 ≤ 第三边时拒绝创建），支持周长与面积
- **抽象类设计**：`Shape(ABC)` 定义 `perimeter()` / `area()` 接口，多态统一调用
- **进阶扩展**：
  - 等腰 / 等边 / 直角三角形判定
  - 椭圆（拉马努金周长近似公式）
  - 多边形（鞋带公式求面积）
- **可视化界面**：坐标纸风格 Canvas 画布，点击添加点、参数绘制图形、实时输出周长/面积/类型，非法三角形即时拒绝

## 合法性检查说明

三角形初始化时自动校验，不满足则抛出 `ValueError`：

1. **三点不共线**：三点构成的三角形面积必须大于 0（叉积法，含浮点容差 `1e-9`）
2. **三角形不等式**：任意两边之和大于第三边
